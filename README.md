## Project Description
This project demonstrates the development of a client-side WebGIS application using HTML, JavaScript, and Leaflet. The application visualizes multiple geospatial datasets for Knoxville, Tennessee, including breweries (points), greenways (lines), and parks (polygons). It highlights how web technologies can be used to create interactive, user-friendly mapping applications for spatial exploration.

## How to View / Run
- View the live web map via GitHub Pages (link in repository)  
- To run locally:
  - Install dependencies: `npm install`  
  - Start the server: `npm start`  
  - Open browser at: `http://localhost:8080`  
- Interact with map layers to explore breweries, parks, and greenways
